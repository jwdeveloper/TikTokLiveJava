title: Getting Started
description: Install TikTokLiveJava and receive comments, gifts, and other events from a TikTok livestream with Java.
---

TikTokLiveJava receives comments, gifts, likes, follows, shares, viewer counts, and other events from a TikTok livestream. Create a client with `TikTokLive.newClient("host-name")`, register listeners for the events you need, and connect. Start with [Install](/getting-started/install/), then read the [connection lifecycle](/getting-started/connection/).
